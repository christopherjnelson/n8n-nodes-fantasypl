# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [0.1.0] - 2026-08-19

### Added

- Initial release of `n8n-nodes-fantasypl`
- **General**: Get Bootstrap Static data (teams, players, gameweeks, settings) and Event Status
- **Fixture**: Get all fixtures, fixtures by gameweek, and filter by upcoming/past fixtures
- **Gameweek**: Get live gameweek stats & points, and dream team of the gameweek
- **Player**: Get detailed player summary, upcoming fixtures, season history, and past seasons history
- **Manager**: Get manager profile, gameweek history, transfer history, and gameweek picks
- **League**: Get Classic league standings, Head-to-Head standings, and Head-to-Head matches
- **Custom API Call**: Support for custom requests to any FPL API endpoint
- Optional Fantasy Premier League API credentials for authenticated endpoints
